# Changelog

## 0.1.0-rc.2

- Published six SDK modules to Maven Central: core, ADK, Firebase, LiteRT-LM, ML Kit and the legacy Gemini Nano adapter.
- Added the first-class `agent-mlkit` integration for ML Kit GenAI Agent and Prompt APIs.
- Retained `agent-gemini-nano` as a legacy compatibility adapter.
- Continued to describe device/runtime qualification and production-readiness gates separately from CI compilation and packaging checks.

## 0.1.0-rc.1

- Initial release candidate publication line for the modular Android agent SDK.
- Introduced the backend-neutral core and initial ADK, Firebase, LiteRT-LM and Gemini Nano integration artifacts.

This changelog summarizes release-level changes. Consult the source release history for implementation-level details.
