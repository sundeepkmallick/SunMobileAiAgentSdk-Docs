# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for the SDK project where available, or contact the maintainer through the contact information published on the GitHub profile. Include the affected artifact/version, impact, reproduction steps and any relevant logs with secrets and personal data removed.

## Scope

Security review should consider the SDK core, backend adapters, tool execution boundaries, sample application and integration guidance. Host applications remain responsible for identity, authorization, credentials, consent, AppFunctions security and validation of consequential operations.

## Supported versions

The project is currently distributed as a release candidate (`0.1.0-rc.2`). Security fixes and support expectations for release candidates may change; check the repository release notes for current status.

Please allow the maintainer reasonable time to investigate and coordinate a fix before public disclosure.
